2. Device preflight

  • Expected package: za.co.portalfred.christmaslunch.debug; version 1.0-debug.
  • Compatibility: minSdk 26, targetSdk 35, arm64-v8a. Redmi Note 10 Pro is the intended device.
  • Enable Settings → Additional settings → Developer options → USB debugging.
  • Also enable Install via USB and USB debugging (Security settings) where MIUI exposes them.
  • Approve the “Allow USB debugging?” prompt. If adb devices says unauthorized, revoke USB debugging authorisations and reconnect.
  • Record: Android version, MIUI version, Android System WebView version, device model, and whether the phone has a SIM/Mi account (this affects some MIUI toggles).
If MIUI blocks Install via USB: skip ADB and copy the current app-debug.apk to the phone, open it from Files, allow “install from this source”, and tap Install. That is an equally valid debug sideload test.

3. Install and launch

ADB path

adb devices -l
adb install -r menu-change-apk/recipe-apk/android/app/build/outputs/apk/debug/app-debug.apk
adb shell monkey -p za.co.portalfred.christmaslunch.debug -c android.intent.category.LAUNCHER 1

If you copied the APK to the phone instead, install app-debug.apk from the Files app and launch Xmas Lunch manually.

Verify installed package

adb shell dumpsys package za.co.portalfred.christmaslunch.debug | grep -E 'versionName|versionCode|firstInstallTime|lastUpdateTime'

Expected: versionName=1.0-debug, versionCode=1, and no install error.

4. First-run MIUI setup

Open Xmas Lunch → More → MIUI reliability:

  1. Battery optimisation: set to No restrictions; enable Autostart if present.
  2. Exact alarms: allow Alarms & reminders / exact alarms.
  3. Notifications: allow notification permission and the Cook timers channel.

These are required for reliable native timers, foreground Cook Mode, TTS, and notifications. Without exact-alarm permission, the app intentionally falls back to a windowed in-app timer.

6. If something fails

Capture the screen plus these details:

  • Exact step, tab, viewing date, portion count, and expected vs actual result.
  • Android version, MIUI version, WebView version, device model.
  • The current recipe-supplied run ID and artifact ID used, and whether sha256sum -c apk.sha256 passed.
  • Whether airplane mode, notification permission, exact alarms, battery “No restrictions”, and Autostart were enabled.
  • If available, a filtered logcat from the moment of failure.
