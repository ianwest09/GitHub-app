# First milestone architecture and checklist

- React + Vite UI, loopback FastAPI service, GitHub REST API, JSON cache and encrypted vault. No external databases or paid services.
- Data: in-memory authenticated profile and reported classic token scopes; scrypt/Fernet encrypted token and salt; cache keyed by connected account, containing repository metadata and fetch timestamp. The process never persists the passphrase. A local audit log records GitHub writes, console commands and script saves/runs; it is not tamper-proof and does not include read calls.
- API reads `/user`, all pages of `/users/ianwest09/repos`, and, when authenticated as ianwest09, all pages of `/user/repos` filtered to that owner. Cache is used when available and as a fallback after refresh errors. GitHub's issue count includes PRs. Results are limited to 10,000 entries per endpoint; hitting that limit returns an error rather than silently caching a partial list.
- Security: bind only to loopback, validate Host and Origin, require a custom header on POST and an in-memory local-access session for API calls, set private file modes, never log request bodies or tokens, use HTTPS to GitHub, and disable access logs in startup instructions. Do not expose Vite to a network. Local processes and browser extensions remain in the threat model. Cache metadata is not encrypted. Optional restricted command execution, script execution and explicitly confirmed GitHub writes are included; see the README for their limitations. The API requires a separate configured local-access passphrase, but same-user processes or a compromised device may still access secrets.
- Fine-grained token: repository metadata read; select only necessary repositories. Later write features must document their additional permissions and require explicit confirmation before each mutation.
- Plan: read-only repository views; explicit-confirmation writes; independently designed and approved Termux bridge; script editor; Arena prompt library; dashboard, audit and offline improvements. Each stage requires approval.
